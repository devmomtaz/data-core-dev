The Challenge

The legacy Excel file-based setup had accumulated significant operational friction and data degradation over years of uncoordinated multi-user entries:

  • Severe Data Redundancy: Identical data columns were manually replicated across multiple Excel sheets, creating synchronization conflicts.
  • Duplicate & Corrupted Records: Historical worksheets contained duplicate entries, missing key fields, and unverified transactional data.
  • Formula & Calculation Errors: Broken cell references and hardcoded manual overrides led to inaccurate financial and operational metrics.
  • Concurrency & Locking Issues: Frequent file corruption and multi-user locking when staff attempted to update workbooks simultaneously.

Migration Engineering Process

  1. Schema Normalization: Extracted unnormalized Excel/Access tables and redesigned them into 3NF MySQL relational schemas.
  2. ETL & Data Cleansing: Scripted automated Python & PHP data pipelines to validate, deduplicate, and sanitize historical records during import.
  3. Web UI Implementation: Built a responsive, familiar web dashboard using Bootstrap and JavaScript that eliminated the learning curve for staff.
