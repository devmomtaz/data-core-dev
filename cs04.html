Borrower's Balance Inquiry Mobile App (LoanCheck) in Flutter

Cross-platform mobile application giving borrowers instant access to real-time account balances, payment schedules, transaction histories, and dedicated support.


Client Context: Custom-engineered for Brett Asset Finance (owned by Mr. Conor Brett). Originally commissioned via Guru by first manager Niall O'Niel in August 2015, DataCore Systems provided active development, operational enhancements, and continuous database support from 2015 through 2023, generating a total project value of $17,625 USD.

Executive Summary

To enhance customer self-service and reduce call center workloads, DataCore Systems engineered LoanCheck—a mobile balance inquiry application built with Flutter. Linked with Brett Asset Finance's backend system, the app empowers clients to view up-to-date loan balances, verify recent payment receipts, check upcoming installment due dates, and communicate directly with support teams on mobile devices.

Core Application Features

Home Page Dashboard

Intuitive main navigation hub granting quick access to Account Summary, Payment History, Contact Support, and secure user Sign Out.

Detailed Account Summary

Real-time ledger breakdown including Account Number, Borrower Name, Current Balance, Overdue Amount, Last Paid Date/Amount, and Next Installment Due details.

Payment History

Comprehensive chronological log of historical repayments, payment methods, and transaction confirmation IDs.

Contact Support & Assistance

Direct channel for borrowers to submit account inquiries, request statement documents, or resolve billing discrepancies.

Technologies & Architecture

Flutter Dart RESTful APIs Secure Authentication

Security & Data Integration

The app features end-to-end tokenized authentication to safeguard sensitive financial credentials. Data synchronization communicates securely with the client backend via encrypted REST APIs to ensure that loan balances and payment schedules are always updated accurately.
